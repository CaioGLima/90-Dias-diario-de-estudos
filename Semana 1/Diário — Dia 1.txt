Antes dos exercícios, abra seu material de SQL e revise rapidamente:

WHERE 
:: ele vai adicionar uma condição na nossa pesquisa, filtrando os resultados. Exemplo: Select * From tabela 1 WHERE info1 = 'valorx';

operadores =, <>, >, <, >=, <= 
:: o = vai significar igualdade, ent ele só vai pegar o valor que for igual a nossa condição. já o restante ele vai assumir um sentido de condição, ou seja, caso o valor x seja maior, menor, igual que , menor que etc é isso que eu quero que apareça.

AND / OR 
:: eles vão adicionar mais uma camada de filtro na nossa pesquisa, ent eu quero que o info1 < 'valorx' E ou OU info2 > 'valory' 

IN
:: ele vai pegar o valor que esteja entre uma lista de opções determinada, ou seja, a info1 só vai aparecer se o valorx for(1,7,9,10) 

BETWEEN
:: aqui ele vai filtrar o valor num intervalo determinado, info1 esta no meio de 'valorx' E 'valory' 

LIKE
:: ele vai pegar valores que tenham um caracter coringa( usa % pra isso), ent info1 like 'ca%', ele pega todos os valores que possuam as iniciais ca


IS NULL
IS NOT NULL
:: ele vai verificar e pegar os valores que estejam nulos ou não estejam nulos

CASE WHEN (THEN) (END AS) (From

🟠 Exercício 9 — CASE

Crie uma consulta que mostre:
id | valor | classificacao
E classifique os pedidos assim:
valor >= 300 → "Alto"
valor >= 100 → "Médio"
abaixo de 100 → "Baixo"
--9
SELECT id, valor ,
	CASE 
		When valor >= 300 THEN 'Alto'
    	When valor >= 100 THEN 'Medio' 
    	ELSE 'Baixo'
    END AS classificacao
 FROM Pedidos;

🔴 Exercício 10 — desafio

Liste os pedidos não cancelados, com valor maior que 100.
Depois mostre uma coluna chamada classificacao usando CASE:
= 300 → "Alto"
< 300 → "Normal"
Aqui quero que você combine:
WHERE + AND + CASE
 --10
SELECT *,
    CASE 
        WHEN valor >= 300 THEN 'Alto'
        ELSE 'Normal'
    END AS classificacao
FROM Pedidos
WHERE status <> 'Cancelado'
  AND valor > 100;
